# Clamp Float

Clamp to specified float values

A clip alarm can also be toggled on showing where dark values will be clipped (green) and bright values will be clipped (red).
This shader will clamp in the Stack Colour Space, use a **Colour Space** operator before this shader to convert to another clamping space.

![Screenshot](screenshot-1.jpg)

## Installation

Unzip and place files into the */vol/.support/shaders* folder which is the same as
- **Linux:** /usr/fl/shaders
- **MacOS:** /Library/Application Support/FilmLight/shaders
